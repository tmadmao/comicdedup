**项目**：漫画查重 ComicDedup（本地 Windows 桌面程序）
**最终版本**：v1.2.2
**状态**：⏹ **已无限期停止开发**
**停止日期**：2026-10-08
**许可**：MIT（Copyright (c) 2026 seanfan）

## 一、为什么停止

这个工具**已经在一个真实书库上跑通并长期使用**：3069 本单行本 / 约 10.7 万页漫画
（放在 NAS 上），首次全量扫描后判重、分组、人工核对、移入回收站这一整条链路都实际跑过，
结果符合预期。

**停止的原因是"没有新的具体需求"，而不是遇到技术障碍或放弃维护。**
在没有明确需求的情况下继续改动，只会增加回归风险 —— 尤其这个项目的判据阈值是
拿真实书库标定出来的，动一处就要重新验证一遍，而收益为零。

这意味着：

- 不再有新功能，不再更新下载包；
- Issue / PR 不保证响应；
- **仓库保持公开可读，可自由 fork、修改、二次开发与再分发**（MIT 允许商用，
  只需保留版权声明）。

如果将来出现明确的新需求（比如要支持 PDF 载体、要跨语言同一作品聚合），
可以基于 v1.2.1 的代码重新启动 —— **v1.2.2 相对 v1.2.1 只改了文档与开发脚本，
算法、判据、缓存格式一字未动**，从 v1.2.1 继续最省事。

## 四、已知取舍与限制（如实记录，不再修复）

这些不是"没做完的 Bug"，而是已明确接受的设计取舍，写在这里是为了避免后来者误判。

1. **「建议保留」只是建议。** 判据是「文件名可疑字样 → 分辨率（带 15% 容差）→ 路径长度 →
   体积 → 路径字典序」。为什么分辨率要带容差：自制扫描版按 300dpi 出图，像素数常常
   **略高于**官方 DL 版，可画质其实更脏；不设门槛就会出现「建议删官方 DL、留自制扫描」的
   反直觉结论。最终以界面里选中的那本为准，点「设为保留项」即可覆盖。

2. **页数差很大的两版可能漏判。** 块采样能容忍的偏移上限约等于块长（13 页）。
   实测页数差 21% 的那一对（168 vs 214 页，且缺页集中）就是物理极限，漏了；
   页数差 12% 以内基本能抓回。真遇到合订本，改用「彻底」或「全页」预设。

3. **判据只在抽样页上做，给不出「具体缺哪几页」。** 想知道 A 版比 B 版少了哪几页，
   需要对两本做**全量逐页比对**（本项目没做，参考项目 ComicDup 有这个「按需全量比对」功能）。

4. **漫画的公共页会制造假候选。** 整套书共享的版权页 / 广告页 / 下集预告页是**同一张图**，
   于是不相干的两本也会命中好几页（实测 1.9 万对共享 ≥2 页）。这是 burstiness 的教科书
   案例，靠 LIS 页序成链把它们挡在精比之外（公共页的匹配对页码乱跳，连不成链）。

5. **不支持 PDF 载体**，也不做 OCR（不识别文字，只用分镜图像特征）。PDF 请先用别的工具
   转成图片文件夹或 cbz。

6. **裁剪只在默认模式下调优过。** 出厂 `--crop bed`（只去扫描仪盖板黑边）是实测最优；
   `mass` / `edge` / `paper` 是失败实验的留存，只用于复现 README 里那张对照表，
   不要当成可选优化项。

7. **规模只验证到 3069 本。** 候选书对筛选是「按书分批矩阵乘 + 上三角」，万本级别
   （≈5000 万书对）的耗时与内存没有实测过。真到那个规模，先看日志里的
   `候选筛选 k/N` 与 `精比 n/N` 两行进度。

8. **扫不动的书不会自动重试。** 上次失败（`status='error'`）且文件没变的书，再扫会被
   直接跳过 —— 这是为了避免每次扫描都卡在同一个坏档上。**修完 bug 想让它们重新被扫，
   必须删掉缓存库里的对应记录**（或清空缓存重扫）：
   ```sql
   DELETE FROM books WHERE status='error';
   ```

9. **一次删除最多 500 项**（`delete_paths(max_items=500)`）：这是防误勾的安全上限，
   超出部分不会被处理，重新勾一次即可。

10. **未做代码签名**，个别杀软可能依据启发式规则误报（历史上 360 报过一次「敲诈病毒」，
    根因是旧版往用户目录批量写随机哈希命名的缩略图 jpg，与勒索软件的行为指纹撞车；
    v1.1.1 起缩略图改存 SQLite，这个触发点已消除）。把解压出来的文件夹加进信任区即可。

## 五、如何继续使用

- **普通用户**：从 [Releases](https://github.com/tmadmao/comicdedup/releases/latest) 下载
  `ComicDedupTool-v1.2.2-win64.zip`，解压后双击文件夹里的 `ComicDedupTool.exe`
  （不需要 Python、不需要任何依赖；文件夹要整体使用）。
  7z / rar 仍需本机装有 [7-Zip](https://www.7-zip.org/) 或 WinRAR（zip 不需要）。
- **想用源码**：双击 `安装依赖.bat`，再双击 `运行工具.bat`。
- **先自检**：`python comic_dedup.py --selftest`。
- **批量模式**：`python comic_dedup.py --scan "D:\漫画" --csv 重复清单.csv`。
- **只调阈值不重扫**：`python comic_dedup.py --regroup --csv 重复清单.csv`（或界面上的「重新分组」）。
